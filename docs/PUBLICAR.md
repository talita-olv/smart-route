# Publicação no GitHub Pages

Repositório independente: https://github.com/talita-olv/smart-route

1. No repositório, abrir **Settings → Pages**.
2. Em **Build and deployment**, escolher **Deploy from a branch**.
3. Selecionar **main** e **/(root)**; salvar.
4. Esperar a publicação e conferir o endereço exibido pelo próprio GitHub. O endereço esperado é https://talita-olv.github.io/smart-route/ mas só deve ser divulgado depois de funcionar.
5. Abrir o link e testar Carregar exemplo, Gerar sugestão de rotas e os downloads de Excel/CSV.

O site é estático. Não precisa de backend para a demonstração. Integrações corporativas são projetos separados e autorizados.
